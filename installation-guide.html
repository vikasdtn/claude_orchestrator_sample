Installation Guide

📘 What This Document Covers

Purpose: This guide walks you through setting up and deploying the Multi-Agent Orchestrator Utility Agent System from scratch.

Who should use this: DevOps engineers, system administrators, or developers setting up the system for the first time.

What you'll learn: How to install prerequisites, configure AWS, deploy infrastructure with Terraform, build Docker images, and troubleshoot common setup issues.

Prerequisites

Required Software

  • Python 3.11+
  • Docker 24.0+ with buildx support
  • Terraform 1.5+
  • AWS CLI v2
  • Git

AWS Requirements

  • AWS Account with appropriate permissions
  • Bedrock model access enabled (Claude 3 Sonnet)
  • Bedrock AgentCore access enabled
  • ECR repository access

Quick Start

1. Clone and Setup

git clone <repository-url>
cd contact-center-agents

# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -e ".[dev]"

2. Configure AWS

# Configure AWS CLI
aws configure

# Verify Bedrock access
aws bedrock list-foundation-models --query "modelSummaries[?contains(modelId, 'claude')]"

3. Set Environment Variables

export AWS_REGION=us-east-1
export BEDROCK_MODEL_ID=anthropic.claude-3-sonnet-20240229-v1:0
export AGENTCORE_GATEWAY_URL=<your-gateway-url>

Deployment

Infrastructure Deployment

cd infrastructure

# Initialize Terraform
terraform init

# Review the plan
terraform plan -var-file=environments/dev.tfvars

# Apply infrastructure
terraform apply -var-file=environments/dev.tfvars

Build and Push Docker Images

cd ..
chmod +x scripts/build_and_push.sh
./scripts/build_and_push.sh

Deploy to AgentCore

DEPLOY=true ENVIRONMENT=dev ./scripts/build_and_push.sh

Verify Deployment

terraform output orchestrator_runtime_arn

Configuration

Variable Description Default
AWS_REGION AWS region us-east-1
BEDROCK_MODEL_ID Claude model ID anthropic.claude-3-sonnet-20240229-v1:0
AGENTCORE_GATEWAY_URL Gateway URL -
LOG_LEVEL Logging level INFO

Local Development

Running Tests

./scripts/run_tests.sh
pytest tests/test_orchestrator.py -v
pytest --cov=shared --cov=orchestrator --cov=agents

Local Docker Compose

docker-compose up -d
docker-compose logs -f orchestrator
docker-compose down

Production Deployment

cd infrastructure
terraform apply -var-file=environments/prod.tfvars

Troubleshooting

ECR Authentication Failed

aws ecr get-login-password --region $AWS_REGION | \
  docker login --username AWS --password-stdin \
  <account-id>.dkr.ecr.$AWS_REGION.amazonaws.com

Bedrock Access Denied

  • Verify model access in AWS Console
  • Check IAM role permissions

AgentCore Runtime Issues

aws logs tail /aws/bedrock/agentcore/contact-center-dev --follow
